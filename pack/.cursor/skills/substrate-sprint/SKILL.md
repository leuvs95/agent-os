# Substrate sprint (P4)

Ninety minutes of *how this named substrate dies*. No hub template to walk.

## Procedure

1. Confirm the name is on the constitution table. If not, `/amend-north-star`.
2. Open **official sources**. Do not teach from another project’s folklore.
3. Ask the six kernel lenses. Operate only if this substrate remembers, bills,
   retries, schedules, or leaks.
4. Owner writes **five questions they could not have asked an hour ago**.
5. Write/update `docs/agent-os/substrates/<name>.md` and learned rows in
   `docs/agent-os/CATALOG.md`.

## Done when

The owner can ask this substrate’s Belief and Operate questions without prompting.

## Not done when

They watched you explain a previous product’s database.
