# Grill me

Subroutine, not project start. If `CONSTITUTION.md` is a stub, run
`/build-north-star` instead.

`/unit-unlock` already forces the failure catalog. This skill walks one
branch when the owner wants more interrogation than the current seat.

## Mandate

Interview until the plan can execute without hidden defaults. Depth-first.
One consequential question at a time. After answers, mirror:

```text
Decision:
Evidence:
Assumption:
Default if we stop talking:
Reconsider when:
```

## Before asking

Read `WORKING_STATE.md`, `docs/agent-os/KERNEL.md`, `docs/north-star/CONSTITUTION.md`, `docs/agent-os/CATALOG.md`.
Inspect instead of quizzing.

## Tree (adapt, do not force)

```text
Purpose
├── Complexity
├── Unknowns (seats / substrates)
├── Belief (gate / eval)
├── Judgment (own vs delegate)
└── Operate (only if named substrate makes it real)
```

Classify gaps: learning vs evidence vs decision vs execution.
Never quiz an evidence gap.

## Stop

Owner says it is clear, time-boxes, switches to execute, or deadline mode.
Dump shared understanding. Do not continue.
