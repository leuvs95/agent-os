# Kernel — lenses, staffing, learned-only

The OS kernel is **risk-driven SDLC + AI-native judgment**, not an ops
spreadsheet from the last hosted pipeline.

| Lens | SDLC | AI-native |
|---|---|---|
| Purpose | requirements | the pitch is not the product |
| Complexity | design (Ousterhout) | agents invent layers and second paths |
| Unknowns | planning | name seats/substrates you have no word for |
| Belief | verification | eval where output is not binary; independent gates |
| Judgment | ownership | agent executes; human owns decisions; generation vs comprehension |
| Operate | run | only if something remembers, bills, retries, schedules, or leaks |

Ladder order = risks on the path to the observable product outcome, not
any risk retired, not components built.

Anti-patterns: dated mega North Stars; status inside the constitution;
`/grill-me` as genesis; importing last project’s substrate files;
filling nine ops categories because they exist.
