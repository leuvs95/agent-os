Kernel-local. Not imported. Pass if / Fail if and the 30 fixture names/expect codes are frozen. The checker conforms to them; do not change fixtures to match the implementation.

**Contract:** Parent tree determines the epoch; the proposed/resulting tree must still be structurally valid. `accepted` is monotonic: once established in history, a later commit may neither revert it to stub nor remove the constitution. Evaluate commit-by-commit, never as one aggregate PR diff. Pack exemption is a repository-shape assertion (`pack/docs/agent-os/KERNEL.md`), not a security boundary.

## Probe

Fixture stories: `scripts/check-fixtures/matrix.sh`. Integrity (recipes construct):

```
scripts/check-fixtures/build-all.sh
```

After the checker exists, one stranger command (must not change these criteria):

```
scripts/check-fixtures/run.sh
```

`run.sh` builds each story in a temp repo and invokes `pack/scripts/agent-os-check.sh` per `MODE`. Exit 0 only if every actual exit code matches `EXPECT`.

MODE:

- `range` — `--range <empty-tree>...<HEAD>` (empty tree only because the fixture asks; production never guesses it)
- `staged` — `--staged` (HEAD is parent; index is the proposed commit)
- `no-base` — no `--range`, no `--staged`, no remotes, no tracking branch

## Pass if

`build-all.sh` exits 0 (every recipe constructs). After the checker exists, `run.sh` exits 0: these stories exit 0 from `agent-os-check.sh`:

- `bootstrap-docs` — no constitution; allowlisted `README.md` only
- `bootstrap-add-stub` — first commit adds `docs/north-star/CONSTITUTION.md` with exactly `Status: stub`
- `stub-docs-main` — `Status: stub`; docs-only on `main`
- `accept-on-main` — parent stub, result `Status: accepted`, allowlist only, branch `main`
- `accepted-docs-unit` — accepted epoch; `unit/1-ingest`; id `1` on ladder; docs-only
- `gate-then-code` — A `gates/1.md`, B `src/x.py`
- `later-gate-edit` — gate exists, implementation landed, later commit edits `gates/1.md` only
- `slug-decoration` — accepted; branch `unit/1-other`; id `1` on ladder; docs-only
- `pack-exempt` — `pack/docs/agent-os/KERNEL.md` present plus `src/x.py`

## Fail if

`build-all.sh` cannot construct a named story. After the checker exists, `run.sh` exits 0 only if these stories exit 1:

- `bootstrap-src` — no constitution; `src/x.py`
- `bootstrap-add-malformed` — first commit adds constitution that is not exactly `Status: stub` or `Status: accepted`
- `status-missing` — constitution file exists, no `Status:` line
- `status-duplicate` — two `Status:` lines
- `status-unknown` — `Status: unwritten`
- `status-trailing` — `Status: accepted` plus trailing space
- `stub-src` — `Status: stub` plus `src/x.py`
- `accepted-main` — parent `Status: accepted`; any change on `main`
- `accepted-ladder-missing` — accepted epoch; no `LADDER.md`
- `accepted-ladder-empty` — canonical header, zero data rows
- `accepted-ladder-empty-id` — data row with empty Id cell
- `accepted-ladder-bad-header` — header is not the exact two bytes
- `same-commit-gate-code` — `gates/1.md` and `src/x.py` in one commit
- `code-first-gate-later` — A accepted docs, B `src/x.py`, C `gates/1.md`, D more src
- `impl-deletes-gate` — implementation commit removes `gates/1.md`
- `id-not-on-ladder` — branch `unit/9-missing`; `9` not an Id cell
- `merge-in-unit-range` — merge commit (`--no-ff`) on `unit/1-ingest`
- `accepted-revert-stub` — parent accepted; result `Status: stub`
- `accepted-delete-constitution` — parent accepted; constitution file removed
- `docs-only-non-unit-branch` — accepted; branch `hotfix`; docs-only
- `no-base` — no `--range`, no tracking branch, no `origin/main` or `origin/master`

A range that would pass if the checker only looked at the aggregate diff (`code-first-gate-later`) must still fail.

A merge commit in the inspected range must fail even if both sides are allowlisted docs. The MMU does not attribute paths through merge parents.
